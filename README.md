# TIL

このリポジトリは、日々の学習内容を記録するための **TIL (Today I Learned)** リポジトリです。
技術書や公式ドキュメント、ハンズオン、業務を通じて学んだ内容を、自分の言葉で整理し、知識の定着を目的としてまとめています。

## 目的

- 学習内容をアウトプットし、理解を深める
- 技術的な知識を継続的に蓄積する
- 後から見返せる自分専用のナレッジベースを作る
- 学習の継続を習慣化する

- セキュリティ

- その他、業務や資格学習で得た知識

## 記録ルール

各記事では以下の内容を意識して記録しています。

- 学んだこと
- 自分なりの理解
- 業務や実務との関連
- 疑問点や追加で調べた内容
- 参考資料

自分の理解を整理し、自分の言葉でまとめることを心掛けています。

## 学習ポリシー

- 毎日少しでも学習した内容を記録する
- 完璧を目指さず、継続することを優先する
- 誤りや理解が深まった内容は随時更新する
