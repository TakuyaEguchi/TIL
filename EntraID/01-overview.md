# Microsoft Entra ID Overview

## 概要

Microsoft Entra IDは、Microsoftが提供するクラウドベースのID・アクセス管理（Identity and Access Management：IAM）サービスです。

Microsoft 365やAzureをはじめとするクラウドサービスの認証基盤として利用されており、ユーザー認証やアクセス制御を一元管理できます。

以前は **Azure Active Directory（Azure AD）** という名称でしたが、Microsoft Entraファミリーの一部として **Microsoft Entra ID** に名称変更されました。

## なぜ必要なのか

企業ではMicrosoft 365やSalesforceなど複数のクラウドサービスを利用することが一般的です。

サービスごとにIDやパスワードを管理すると、

- パスワードの使い回し
- アカウント管理の負担
- 退職者アカウントの削除漏れ
- セキュリティリスク

といった課題が発生します。

Entra IDを利用することで、ユーザーやアクセス権限を一元管理でき、安全かつ効率的な認証基盤を構築できます。

## Microsoft Entra IDでできること

主な機能は以下のとおりです。

| 機能 | 概要 |
|------|------|
| ユーザー管理 | ユーザーやグループを管理する |
| 認証 | ユーザー本人であることを確認する |
| シングルサインオン（SSO） | 一度の認証で複数のサービスを利用できる |
| 多要素認証（MFA） | パスワード以外の認証要素を追加する |
| 条件付きアクセス | 条件に応じてアクセス可否を制御する |
| アプリケーション連携 | Microsoft 365やSaaSと連携する |

## 主な構成要素

### テナント

組織専用の管理領域です。

ユーザーやグループ、ライセンス、アプリケーションなどはテナント単位で管理されます。

### ユーザー

Entra IDに登録される利用者です。

社員だけではなく、ゲストユーザーを登録することもできます。

### グループ

ユーザーをまとめて管理するための仕組みです。

アクセス権限をまとめて付与できるため、管理を効率化できます。

### ロール

管理者権限を定義する仕組みです。

必要最小限の権限を付与することで、セキュリティ向上につながります。

## Active Directoryとの違い

| 項目 | Active Directory | Microsoft Entra ID |
|------|------------------|--------------------|
| 管理場所 | オンプレミス | クラウド |
| 管理単位 | ドメイン | テナント |
| 主な用途 | 社内システム | Microsoft 365・SaaS |
| 認証対象 | Windows中心 | クラウドサービス中心 |

オンプレミス環境ではActive Directoryが中心でしたが、クラウド利用が増えた現在ではEntra IDが認証基盤となるケースが増えています。

---

## 利用例

例えばMicrosoft 365を利用する場合、

1. Microsoft 365へアクセスする
2. Entra IDがユーザーを認証する
3. 認証に成功するとTeamsやSharePointなどを利用できる

このように、Entra IDはMicrosoft 365の認証基盤として動作しています。


## 業務との関連

これまでMicrosoft 365のアカウント管理やActive Directoryの運用に携わっていました。

Active Directoryはオンプレミス環境を前提としたID管理サービスであり、社内ネットワークを中心とした運用に適しています。一方で、リモートワークの普及やクラウドサービスの利用拡大に伴い、場所やデバイスを問わず安全にアクセスできる認証基盤が求められるようになりました。

今回学習したことで、Microsoft Entra IDはクラウド時代の認証・アクセス管理を担うサービスであり、Microsoft 365をはじめとするさまざまなクラウドサービスを安全に利用するための基盤となっていることを理解しました。

## 学んだこと

- Entra IDはクラウドのID・アクセス管理サービスである
- Microsoft 365の認証基盤として利用される
- ユーザーやアクセス権限を一元管理できる
- MFAや条件付きアクセスなど、ゼロトラストを実現するための機能を提供している
