# AWSアカウントの作成

## 概要

AWSを利用するためのアカウントを作成し、各種サービスを利用できる環境を準備する。

## なぜ必要か

AWSの各サービス（EC2、S3、IAMなど）を利用するための基盤となる。また、学習環境や検証環境を構築するための最初のステップである。

## 手順

1. AWS公式サイトへアクセスする
2. メールアドレスとアカウント名を登録する
3. 住所や支払い方法を登録する
4. SMSによる本人確認を行う
5. サポートプランを選択する（学習目的のため今回は**ベーシックサポート**を選択）

## 学んだこと

- ルートユーザーはアカウント管理専用として利用し、日常的な作業には使用しない。
- ルートユーザーにはMFA（多要素認証）を設定し、セキュリティを強化する。
- 実際の運用や学習では、必要な権限を付与したIAMユーザーで作業する。

## 詰まったこと

- 以前作成したAWSアカウントで無料利用枠を使用していたため、新しいアカウントでも無料利用枠の対象外となっていた。

## 気づき

- AWSアカウントを作成しただけではセキュリティ設定は十分ではない。
- アカウント作成後は、MFAの設定やIAMユーザーの作成、Billing Alarmの設定など、初期設定を行うことが重要である。
